# Developing DAWG

| Path | What |
|---|---|
| `DAWG.lua` | The engine, a single file. Everything the mission needs. |
| `DAWG_borders_caucasus.lua` | Generated by `tools/make_borders.py` from Natural Earth 10m admin-0 (de jure borders + 12 NM sea strips). |
| `DAWG_config_template.lua` | Every option, commented (ships). |
| `DAWG_config_Caucasus.lua` | Real-border example config (ships as `examples/`). |
| `build_dawg_starter.py` | Builds the Starter mission, set up the no-Lua way. |
| `build_dawg_demo5.py` + `dawg_demo5.lua` + `DAWG_demo5_overrides.lua` | Builds the five-intercept spectator demo and its director script. |
| `dawg_build_common.py` | Shared pydcs helpers. |
| `tests/` | Mock DCS (`mock_dcs.lua`) plus the scenario, config, starter, demo and lane tests. |
| `tools/package.py` | Assembles the release zip. |

## Requirements

- Python 3 with [pydcs](https://github.com/pydcs/dcs) (`pip install pydcs`) for the mission builders.
- DCS's own Lua 5.1 interpreter for the tests: `bin\luae.exe` in any DCS World or DCS Dedicated Server install. Point `DAWG_LUAE` at it if it isn't at `D:\DCS World Server\bin\luae.exe`.

## Build, test, package

```
python tests/run_all.py --runs 3      # every offline test
python build_dawg_starter.py 1.1      # builders never overwrite: bump the version
python build_dawg_demo5.py            # VERSION is set inside the file
python tools/package.py               # tests + engine-match check -> dist/DAWG_v<ver>.zip
python -I tools/make_borders.py ne_10m_admin_0_countries.geojson   # regenerate the borders
```

Mission builders write to `Saved Games\DCS\Missions`. The packager refuses to bundle a mission whose embedded `DAWG.lua` differs from the release copy.

## The mock

`tests/mock_dcs.lua` is a small mission-scripting environment with a kinematic "flight model" (AI flies straight at its waypoint at a capped speed). It deliberately reproduces what the real engine did to us:

- `math.randomseed`, `os`, `io` and `lfs` are absent (DCS strips them from mission scripts).
- The DCS **Follow** task doesn't hold on another coalition's group, so shows must steer.
- A tool-added country (USSR, 68) spawns **neutral** through `coalition.addGroup`, so DAWG must pick and verify a country.
- Named Mission Editor flags (string flag names) work.

Its Caucasus `coord.LLtoLO` is a cubic fit to pydcs's projection (under 4 m error), so config lanes and units from a real `.miz` share one frame.

## Logs

Run a mission and search `dcs.log` for `DAWG|`. The `SHOW_STEP` lines say whether each pass reached its slot (`in slot`) or timed out. That's the line to check when you change the formation controller.
